# ResistanceIQ — Release Notes: Version 1.0.0

**Release Date:** August 18, 2026  
**Application Version:** `v1.0.0`  
**Model Version:** `v1.0.0-ridge-ecfp4`  

---

## 1. Overview & Capabilities

ResistanceIQ Version 1.0.0 represents the initial production release of the agrochemical resistance forecasting and discovery intelligence platform.

### Key Capabilities Included:
- **Molecular Featurization & Live Scoring**: Real-time RDKit 1024-bit Morgan ECFP4 fingerprint featurization with sub-millisecond ($<1.0\text{ ms}$) Ridge regression scoring.
- **Finite-Sample Conformal Uncertainty**: Guaranteed $90\%$ split conformal prediction intervals $[\text{RR}_{\text{lower}}, \text{RR}_{\text{upper}}]$ derived from calibration residuals.
- **Out-of-Domain Detection**: Automatic Morgan Tanimoto similarity auditing ($T_{\max} < 0.25$) preventing silent extrapolation into novel unobserved chemotypes.
- **Multi-Tenant Organization Security**: Strict database query scoping on `organization_id` protecting proprietary lead series.
- **Role-Based Access Control (RBAC)**: Fine-grained permissions for `ADMIN`, `ANALYST`, and `VIEWER` roles.
- **Audit-Ready Reporting**: Exportable PDF dossiers and CSV exports containing complete target metadata and method disclaimers.
- **Production Observability**: Request correlation tracing (`X-Request-ID`), structured JSON logging, and admin telemetry monitoring.

---

## 2. Scientific Limitations & Statutory Disclaimers
- **Development Model Designate**: Model `v1.0.0-ridge-ecfp4` is trained on the benchmark APRD bioassay split ($N=15$). Predictions represent in-silico decision-support estimates and do not replace statutory laboratory bioassays for EPA/EFSA regulatory filings.
- **Target Site Mutations**: Structural hotspot delta-delta-G ($\Delta\Delta G$) rankings are computational guidelines and subject to species-specific receptor polymorphisms.
