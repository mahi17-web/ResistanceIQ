## 3. Leakage Quarantine Guarantee

The following variables are **strictly quarantined** and excluded from the feature space:
- `publication_year` (Post-event publication delay)
- `reference` / `citation` (Author/literature memorization)
- `resistance_type` (Post-event field outcome label)
